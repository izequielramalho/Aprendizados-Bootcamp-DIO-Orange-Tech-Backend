
# Bootcamp DIO Orange Tech+ Backend - Resumo do Aprendizado

Repositório criado para documentar tudo que aprendi durante 
o bootcamp Orange Tech+ Backend da DIO.

## Módulos Concluídos

### Pensamento Computacional
Forma lógica e organizada de resolver problemas através de 4 pilares:
decomposição, reconhecimento de padrões, abstração e algoritmo.

### Lógica de Programação
Base de tudo — sequência, condicionais, repetições, variáveis, 
funções, tipos de dados, vetores e matrizes.

### Introdução ao Desenvolvimento
Diferença entre hardware e software, áreas do mercado como 
Front-end, Back-end e Full Stack, diferença entre UX e UI 
e paradigmas de programação como OOP.

### Git e GitHub
Controle de versão e portfólio — comandos principais como 
add, commit, push, pull e clone, ciclo de vida dos arquivos, 
autenticação com SSH e Token e resolução de conflitos em equipe.

### Sintaxe Java
Anatomia de classes, tipos e variáveis, operadores, métodos, 
escopo, palavras reservadas, JavaDoc, Scanner e argumentos via terminal.

### Lógica Condicional e Controle de Fluxos
Operadores relacionais e lógicos, controle de fluxo com 
if/else e switch, blocos de código e boas práticas de desenvolvimento.

### Estruturas de Repetição e Arrays
For, while, do while, for each e arrays — estruturas para 
repetição e armazenamento de múltiplos valores.
